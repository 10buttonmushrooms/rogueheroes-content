# rogueheroes-content

What Rogue Heroes downloads: the game's asset bundles and app updates. Everything here is written by `tools/rh/publish_cdn.py`, so don't edit it by hand.

**The bundles are not in this file list.** They are release files, in the [`packs` release](https://github.com/10buttonmushrooms/rogueheroes-content/releases/tag/packs). This branch only holds readable copies of the index.

| Where | What |
|---|---|
| [`packs`](https://github.com/10buttonmushrooms/rogueheroes-content/releases/tag/packs) | 2915 bundles in 4 `.bin` packs (678 MB). The game reads each bundle straight out of a pack. |
| [`content`](https://github.com/10buttonmushrooms/rogueheroes-content/releases/tag/content) | `content.json`, which lists every bundle's pack, position, size and md5, and the asset paths manifest. |
| [`app-<version>`](https://github.com/10buttonmushrooms/rogueheroes-content/releases) | App updates. |
| `content.json`, `summary.json` | Copies of the index for reading. Content version 11052. |
